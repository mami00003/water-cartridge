浄水器カートリッジ逆引き ／ クリナップ／OEM

キッチンメーカーの品番は、中身が別の会社

システムキッチンに最初から付いていた水栓は、品番で検索しても情報が出てきません。クリナップが「［LIXIL社製］」と書いて売っている例など、公式の記載から読み取れるOEMの対応関係をまとめました。

品番で検索しても出てこない理由

システムキッチンに最初から付いていた水栓は、カートリッジにキッチンメーカー自身の品番が振られています。作っているのは水栓メーカーや浄水器メーカーなので、キッチンメーカーの品番で検索しても情報が出てきません。公式の記載から読み取れる対応関係を並べました。

クリナップ ZSRBZ045J20AC

ZZJFNA411SY(N)（クリナップの水栓）→ ZSRBZ045J20AC → ［LIXIL社製］

クリナップが自社の品番でカートリッジを売っていますが、商品名そのものに ［LIXIL社製］ と書かれています。

つまり、キッチンを買ったときに付いてきた水栓の品番で検索しても、作っているのは別の会社です。

出典

クリナップ P-35TCL / TK-HB41C1CL / TKB6000C1CL

パナソニックの品番 + 末尾「CL」= クリナップ版

パナソニック本家の TK-HB41C1 に対して、クリナップの適合表にあるのは TK-HB41C1CL。末尾に CL が付いただけです。P-35MJR と P-35TCL、TKB6000C1 と TKB6000C1CL も同じ関係に見えます。

クリナップの適合表はこれらを「パナソニック製」と書いています。

出典

LIXIL UZC2000-SW / CNC0001T-SW2

LIXILの適合表に、クリンスイのカートリッジが載っている

LIXIL の適合表には UZC2000-SW「クリンスイ 交換用浄水カートリッジ」 が載っています。クリンスイ側の品番は UZC2000。

さらにクリンスイの公式ストアでは、現行の HUC17021 のページに「UZC2000、BUC12001」と旧品番が並んでいます。つまり UZC2000 → HUC17021 の置き換えです。LIXIL の適合表だけを見ていると、この置き換えには気づけません。

出典

クリナップ JF22FK / JF21TK / JF20TK

LIXILの JF-22 / JF-21 / JF-20 と同じ並びの品番

クリナップが売っている JF22FK（15+3物質・¥19,800）、JF21TK（12+1物質・¥15,510）、JF20TK（5+1物質・¥12,210） は、LIXIL の JF-22 / JF-21 / JF-20 と型番の並びも除去物質数も一致します。

ただし価格は LIXIL 側（JF-22 ¥4,950 / JF-21 ¥5,170 / JF-20 ¥4,070）の3〜4倍です。本数などの条件が公式の記載から読み取れないので、同じ品物とは断定できません。買う前に入り本数を確認してください。
